# C++ Programming Labs & Practice Work

Welcome to my repository containing a collection of C++ programs, university lab tasks, and practice exercises. This collection highlights fundamental programming concepts, control structures, and algorithmic logic.

---

## 📂 Repository Contents

This repository includes various foundational C++ scripts and their compiled executables:

* **Control Structures & Logic:** Implementation of `switch-case` statements, conditional branching, and decision-making tasks.
* **Loops & Iteration:** Examples utilizing `while` loops, including multiplication table generators and conditional iteration.
* **Fundamental Operations:** Basic arithmetic operations (e.g., sum calculations) and introductory syntax tasks.
* **Lab Work:** Sequentially numbered lab assignments (`Lab 1` to `Lab 5`) covering core programming exercises.

---

## 🛠️ Technologies Used

* **Language:** C++
* **Environment:** Local C++ IDE / Compiler (e.g., Dev-C++, Code::Blocks, or VS Code)
